# Obed Ur Rahman — Data Science Portfolio

Modern Next.js portfolio with Framer Motion animations, responsive dark UI and downloadable resume.

## Run locally
1. Install Node.js 20 or newer.
2. Open this folder in VS Code.
3. Run `npm install` and `npm run dev`.
4. Visit http://localhost:3000.

## Customize before publishing
- Your LinkedIn profile is already connected in the Contact section: https://www.linkedin.com/in/obed-ur-rahman-16377622a/. GitHub is not shown as a public social link.
- Replace the project concept cards with genuine finished projects and verified results. Do not present the concepts as completed work.
- Replace `public/resume.pdf` when you update your resume.
- Verify the employers, roles, dates, experience and skills in your uploaded resume before making the site public.

## Deploy free on Vercel
1. Create a GitHub repository, e.g. `data-science-portfolio`.
2. In this folder run `git init`, `git add .`, `git commit -m "Initial portfolio"`, `git branch -M main`, `git remote add origin https://github.com/YOUR_USERNAME/data-science-portfolio.git`, `git push -u origin main`.
3. At https://vercel.com/new, sign in with GitHub and import the repository.
4. Choose framework Next.js (automatically detected) and click Deploy.
5. Your site will receive a public `*.vercel.app` URL. Later commits to `main` redeploy automatically.
6. Optional: buy a custom domain and attach it under Project Settings → Domains.

Note: No personal photo, fake project metrics, or invented repository links are included.
